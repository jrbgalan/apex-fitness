# Apex Fitness Gym

Apex Fitness Gym is a modern, high-performance web platform for a private fitness club. Built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Classes & Schedules:** Dynamic class listings across 6 categories (Strength, Yoga, HIIT, Cycling, Boxing, Pilates) with intensity ratings, duration, trainer info, and daily schedules.
- **Master Trainers:** Specialist trainer profiles with detailed bios, coaching credentials, and disciplines.
- **Membership Plans:** Tiered membership options (Club Foundation, Apex Performance, Private Suite) with monthly and annual billing.
- **Book a Tour:** Interactive multi-step facility walkthrough and consultation booking.
- **Club Facilities & Gallery:** Rich architectural tour of the training floor, recovery suites, and private studios.
- **Newsletter Subscription:** Instant subscription intake with local state tracking.
- **Authentication & Account:** Member portal login, registration, and password recovery.

## Tech Stack

- **Framework:** React 18 (Single Page Application)
- **Bundler:** Vite
- **Styling:** Tailwind CSS, PostCSS, tailwindcss-animate
- **UI Components:** Radix UI primitives, Lucide React icons
- **Animations:** Framer Motion
- **State & Data Management:** TanStack React Query, Local Storage Client
- **Form Handling:** React Hook Form + Zod validation

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

```bash
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the build locally:

```bash
npm run preview
```
